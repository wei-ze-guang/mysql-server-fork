# MySQL Server Local Dev

Use this skill for this repository:

```text
/Users/macbook/database/mysql-server-fork
```

## Ground Rules

- The first full build has already been completed.
- Build, install, and runtime artifacts stay inside the repository:
  - `_build/mysql-local`
  - `_install/mysql-local`
  - `_runtime/mysql-local`
- Do not install system tools, SDKs, package managers, or global CLIs without explicit user approval.
- Do not delete `_build/mysql-local`; it contains the CMake/Ninja incremental build state.
- Do not maximize CPU during builds. Use `--parallel 8` unless the user asks otherwise.
- For most source changes, build only the `mysqld` target.

## Standard Build Commands

Use this for normal incremental validation:

```bash
cmake --build _build/mysql-local --parallel 8 --target mysqld
```

Only rerun CMake configure when CMake files, options, or source lists changed:

```bash
cmake -S . -B _build/mysql-local -G Ninja \
  -DCMAKE_BUILD_TYPE=RelWithDebInfo \
  -DCMAKE_INSTALL_PREFIX="$PWD/_install/mysql-local" \
  -DWITH_SSL=/usr/local/opt/openssl@3 \
  -DBISON_EXECUTABLE=/usr/local/opt/bison/bin/bison
```

Then build:

```bash
cmake --build _build/mysql-local --parallel 8 --target mysqld
```

Verify the built server:

```bash
_build/mysql-local/runtime_output_directory/mysqld --version
```

## Local Runtime

The local initialized runtime lives here:

```text
_runtime/mysql-local
```

Connect to the local server:

```bash
_install/mysql-local/bin/mysql \
  --protocol=SOCKET \
  --socket="$PWD/_runtime/mysql-local/run/mysql.sock" \
  -uroot
```

Stop it:

```bash
_install/mysql-local/bin/mysqladmin \
  --protocol=SOCKET \
  --socket="$PWD/_runtime/mysql-local/run/mysql.sock" \
  -uroot shutdown
```

Start it:

```bash
WZG_PROBE_LOG="$PWD/_runtime/mysql-local/logs/wzg-probe.jsonl" \
_install/mysql-local/bin/mysqld --daemonize \
  --basedir="$PWD/_install/mysql-local" \
  --datadir="$PWD/_runtime/mysql-local/data" \
  --socket="$PWD/_runtime/mysql-local/run/mysql.sock" \
  --pid-file="$PWD/_runtime/mysql-local/run/mysqld.pid" \
  --log-error="$PWD/_runtime/mysql-local/logs/mysqld.err" \
  --tmpdir="$PWD/_runtime/mysql-local/tmp" \
  --port=3307 \
  --mysqlx=OFF
```

## Code Change Strategy

Keep changes narrow:

- Prefer changing `.cc` files over widely included headers.
- Keep new headers thin. Use forward declarations where possible.
- Avoid including heavy MySQL headers from public module headers.
- Avoid touching `sql/sql_class.h`, global headers under `include/`, or common storage headers unless necessary.
- Avoid unrelated refactors.
- When adding instrumentation, insert short calls/macros at selected points and keep logic in the instrumentation module.

Expected rebuild impact:

- Change only `sql/wzg_probe/*.cc`: rebuild WZG Probe objects and relink `mysqld`.
- Change `sql/wzg_probe/wzg_probe.h`: rebuild every file that includes it.
- Change `sql/sql_parse.cc`: rebuild `sql_parse.cc` and relink `mysqld`.
- Change InnoDB source files: rebuild the touched InnoDB objects and related target, then relink/update server artifacts.

## WZG Probe Notes

The local instrumentation module is:

```text
sql/wzg_probe/
```

Design notes:

```text
wzg-local-doc/wzg-probe-module-design.md
```

Current intent:

- WZG Probe is compiled into `mysqld`.
- WZG Probe currently logs the first connection/command/SQL main-flow events.
- The module uses an independent thread-local context rather than modifying `THD`.
- `connection_uuid` is generated by WZG Probe and should connect connection-layer events with later SQL/handler/storage events on the same server thread.
- Set `WZG_PROBE_LOG="$PWD/_runtime/mysql-local/logs/wzg-probe.jsonl"` when starting `mysqld`; otherwise WZG Probe falls back to `stderr`.

Preferred raw event model:

```jsonc
{
  "schema": "wzg.raw.v1",
  "event_id": 1001,
  "ts_ns": 123456789,
  "duration_ns": 50000,
  "event_name": "sql.mysql_execute_command",
  "event_phase": "end",
  "event_level": "info",
  "thread_id": 8,
  "connection_id": 8,
  "connection_uuid": "conn-8-1",
  "query_id": 42,
  "user": "root",
  "host": "localhost",
  "db": "test",
  "command": "COM_QUERY",
  "sql_command": "SQLCOM_SELECT",
  "raw_sql": "select 1",
  "query": "select 1",
  "error": false,
  "error_code": 0,
  "warning_count": 0,
  "fields": {
    "packet_length": "8"
  }
}
```

Do not over-model ECS inside `mysqld`. Keep server instrumentation as raw JSONL-friendly events. Future visualization/ECS conversion should happen in an adapter outside the hot server path.

Keep `raw_sql` as the original SQL snapshot captured when the server receives a `COM_QUERY`. Later phases may expose rewritten, normalized, or current display SQL separately, but they should keep `raw_sql` for comparison.

### Log Language Convention

Use English for JSON keys and event identifiers. Use Chinese for human-readable values.

Good:

```jsonc
{
  "event_name": "connection.start",
  "message": "连接线程开始处理新的客户端连接",
  "fields": {
    "connection_type": "local_socket",
    "note": "连接对象已创建，准备分配 THD"
  }
}
```

Avoid Chinese keys:

```jsonc
{
  "事件名称": "connection.start",
  "说明": "连接线程开始处理新的客户端连接"
}
```

Reason: English keys keep adapters, filters, and visualization tooling stable. Chinese values keep local debugging readable.

### Readable Value Convention

Keep MySQL execution behavior unchanged, but make logged values human-readable whenever possible.

- Convert internal enums to stable names, for example `COM_QUERY` or `SQLCOM_SELECT`, instead of only logging integer values.
- Convert byte sizes, packet lengths, flags, and status values into explicit fields with readable names.
- For binary protocol payloads, avoid dumping raw binary into JSON. Prefer:
  - decoded text when the protocol field is known and safe to decode,
  - hex preview for short binary values,
  - length plus digest/summary for large binary values.
- Never mutate buffers, THD state, protocol packets, parser state, transaction state, locks, or storage engine state just to make logs readable.
- If a value cannot be decoded safely in-place, log the raw length and a note explaining that decoding was skipped.

Example:

```jsonc
{
  "event_name": "command.dispatch",
  "message": "开始分发客户端命令",
  "command": "COM_QUERY",
  "fields": {
    "packet_length": "42",
    "payload_preview_hex": "73656c6563742031",
    "note": "协议载荷已转换为十六进制预览，未修改原始缓冲区"
  }
}
```
